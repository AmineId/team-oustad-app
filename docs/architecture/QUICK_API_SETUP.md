# 🚀 Configuration API - Ultra Rapide

## ✅ C'est fait !

L'app utilise automatiquement la bonne URL selon la plateforme :
- **Desktop/Web** → `http://localhost:3000`
- **Android Emulator** → `http://10.0.2.2:3000`

## Lancer l'app

```powershell
# Desktop
.\scripts.ps1 run-windows

# Web
.\scripts.ps1 run-web

# Android
.\scripts.ps1 run-android

# URL personnalisée
.\scripts.ps1 run-windows -Url http://192.168.1.100:3000
```

C'est tout ! 🎉
